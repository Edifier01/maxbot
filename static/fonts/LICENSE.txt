# Bundled fonts (offline UI)

The admin panel uses self-hosted fonts — no Google Fonts CDN at runtime.

| File | Family | Weight | License |
|------|--------|--------|---------|
| manrope-400.ttf … manrope-700.ttf | Manrope | 400–700 | SIL Open Font License 1.1 |
| jetbrains-mono-400.ttf, jetbrains-mono-500.ttf | JetBrains Mono | 400, 500 | SIL Open Font License 1.1 |

- Manrope: https://github.com/sharanda/manrope (Google Fonts)
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono
