# MAX Sender

Локальное приложение для текстовой рассылки через мессенджер **MAX** (неофициальный API [PyMax](https://github.com/MaxApiTeam/PyMax)).

## Запуск

**Из исходников:**
```bat
run.bat
```

**Портативный exe (другой компьютер):**
```bat
build.bat
```
Файл: `dist\MAX-Sender.exe` — скопируйте куда угодно. При первом запуске рядом появится папка `data\` (БД, сессии, сообщения). Браузер откроется сам.

Откройте в браузере: **http://127.0.0.1:8765** (если не открылся автоматически)

При первом запуске создаётся виртуальное окружение и устанавливаются зависимости.

## Тесты (smoke)

```bat
run-tests.bat
```

Или вручную:

```bat
venv\Scripts\pip install -r requirements-dev.txt
venv\Scripts\pytest tests\ -v
```

Тесты используют временную папку данных (`MAX_DATA`) и не трогают вашу `data\`.

## UI (offline)

Шрифты Manrope и JetBrains Mono лежат в `static/fonts/` и подключаются локально — **интернет для панели не нужен** (exe и `run.bat`).

## Порядок работы

При **первом запуске** откроется мастер настройки (4 шага):

1. Пароль хранилища сессий (vault)
2. Загрузка файла сообщений (.txt)
3. Создание группы (чат MAX)
4. Подсказка: добавить номер и войти в аккаунт

Кнопка **«Пропустить»** закрывает мастер — всё можно настроить вручную во вкладках.

**Дальше вручную:**

1. **Сообщения** — загрузите `.txt` (одна строка = одно сообщение).
2. **Группы** — создайте группу с ID чата или ссылкой-приглашением.
3. В группе введите номер → **Войти** → SMS и облачный пароль во всплывающем окне.
4. **Рассылка** → **Старт**. Воркер отправит каждое сообщение один раз и остановится.

## Логика рассылки

- Один профиль → одно сообщение → пауза → следующий профиль.
- Пауза по умолчанию **60–180 с** + разброс (jitter).
- Сообщения: случайно без повтора; колода кончилась → перемешать снова.
- Цель: **исчерпать дневные лимиты** (5–12, у новых аккаунтов — прогрев).
- После ошибки / повторного входа — **пауза**; **прокси на группу** (все аккаунты группы → один IP).
- В тексте: спинтакс `{a|b}` и `{{phone}}` / `{{label}}` / `{{date}}` / `{{group}}`.

## Безопасность

| Что | Где |
|-----|-----|
| Сессии MAX | `data/sessions/{id}/session.db.enc` (шифрование Fernet) |
| Ключ шифрования | `data/.app_key` — **не копируйте и не коммитьте** |
| Код API (PIN) | Настройки → опционально. Заголовок `Authorization: Bearer <PIN>` |
| Сервер | Только `127.0.0.1` — не пробрасывайте порт в интернет без PIN |

## ⚠️ Риски

- **Неофициальный API** — MAX может заблокировать аккаунты за автоматизацию.
- **Токены сессии = доступ к аккаунту** — храните папку `data/` в безопасности.
- **Массовая рассылка** — используйте паузы и дневные лимиты; вы несёте ответственность за спам.
- Приложение не связано с разработчиками MAX.

## Структура

```
desktop/
  main.py           — API, воркер, авторизация
  static/index.html — веб-панель
  data/app.db       — SQLite
  data/sessions/    — зашифрованные сессии PyMax

```

## API (кратко)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/status` | Статус, прогресс кампании, лог |
| GET | `/api/profiles/{id}` | Профиль + шаг авторизации |
| GET | `/api/groups/{id}/profiles` | Профили группы (пагинация) |
| GET | `/api/send_log` | История отправок |
| POST | `/api/campaign/start` | Старт (проверяет профили и сообщения) |
| GET | `/api/health` | Проверка здоровья (БД, хранилище, пул, версия) |
| GET | `/metrics` | Метрики Prometheus |

## Desktop-режим

Эта папка не зависит от `server/`. Для серверного Docker/VPS-развёртывания используйте соседнюю папку `../server`.
